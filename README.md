# Refugio Nocturno

Programa de escritorio que genera y produce pistas musicales originales usando los sonidos reales de FL Studio.

- Selección de género (urbano, tropical, música para dormir y más) y de mood.
- Botón "Generar tendencia": compone pistas originales inspiradas en el estilo de los charts de música del momento (sin copiar melodías, letras ni audio).
- Exporta WAV/MP3 y un proyecto .flp editable para FL Studio.

## Créditos

Datos de tempo y tonalidad de canciones proporcionados por [GetSongBPM](https://getsongbpm.com).
